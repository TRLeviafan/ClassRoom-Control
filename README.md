## 🌟 Возможности системы

- 🖥️ **Стриминг экрана в реальном времени**:
  - Аппаратный захват экрана через **Windows Graphics Capture (Direct3D 11)** с нулевой нагрузкой на CPU.
  - Аппаратное кодирование видео **H.264** через Microsoft Media Foundation.
  - Поддержка выбора частоты кадров (15, 30, 60 FPS) и битрейта (2, 4, 8 Мбит/с).
- 🎥 **Запись уроков в MP4**:
  - Одновременный стриминг ученикам и запись урока в высоком качестве с системным звуком и микрофоном учителя.
  - Автоматическая ротация и очистка устаревших записей (30, 60, 90, 180 дней).
  - Автокопирование записей в локальную папку Яндекс.Диска / облака.
- 💬 **Умная интеграция с Telegram**:
  - **Единый бот**: преподавателям не нужно создавать собственных ботов — бот уже настроен в программе.
  - **Автоматический поиск групп**: бот сам находит недавно добавленные группы учебного класса в 1 клик.
  - Быстрая публикация видеозаписи урока, темы и домашних заданий прямо в Telegram-канал класса.
- 📡 **Автообнаружение в локальной сети**:
  - UDP Broadcast (порт 5555) — клиенты учеников мгновенно находят ПК преподавателя без ручного ввода IP-адресов.
- 🛡️ **Встроенная система обратной связи**:
  - Отправка баг-репортов с логами и описанием ошибки прямо разработчику в Telegram.
- 🎨 **Современный Discord-style интерфейс**:
  - Тёмная палитра, плавные скругления, акцентные синие цвета, микроанимации и подсказки.

## 🚀 Быстрый старт

### Для преподавателей
1. Скачайте архив релиза (`ClassRoom_Control_v0.0.1r.zip`) из вкладки [Releases](../../releases).
2. Распакуйте в любую удобную папку.
3. Запустите `ClassRoom Control.exe`.
4. В разделе **Настройки** нажмите **«+ Добавить группу»** и привяжите Telegram-чат класса по кнопке автоматического поиска.

### Для учеников
- Запустите приложение в режиме «Ученик» — программа автоматически подключится к трансляции преподавателя в классе.

## 🛠️ Сборка из исходников

### Требования
- Windows 10 (19041+) или Windows 11
- .NET 8.0 SDK

### Команды сборки

**Обычная сборка:**
```bash
dotnet build -c Release
```

**Автономная сборка (Self-Contained) — запускается на любых ПК без установки .NET:**
```bash
dotnet publish -c Release -r win-x64 --self-contained true -o publish_standalone
```

## 🔒 Безопасность и секреты

Для сборки с собственным Telegram-ботом создайте файл `secrets.json` в корне проекта (на основе `secrets.example.json`):

```json
{
  "TelegramBotToken": "ВАШ_ТОКЕН_БОТА",
  "TelegramDevChatId": "ВАШ_CHAT_ID_ДЛЯ_БАГРЕПОРТОВ"
}
```

> ⚠️ Файл `secrets.json` добавлен в `.gitignore` и никогда не публикуется в репозиторий.
